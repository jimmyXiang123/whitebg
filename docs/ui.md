# 界面设计系统（`whitebg/theme.py`）

界面里的颜色、字号、间距、圆角都不写在界面代码里，而是集中在 `whitebg/theme.py`。
改配色或调整密度只需要动这一个文件，不用在 `gui.py` 里全局搜色值。

## 一、为什么是一套"令牌"而不是随手配色

改造前的情况是：颜色、字号、内边距散落在 `gui.py` 各处，出现 `#007AFF`、`#CFE4FF`、
`#B8C4D6`、`#D00000` 五个蓝色/红色变体，字号有 9/10/11/12/14/24 六档，间距有 6/7/8/10/14/18/20/24
八种取值。结果不是"乱"，而是**没有节奏**——每个数字单看都合理，放在一起就找不到规律。

现在收敛成：

| 维度 | 取值 |
|---|---|
| 间距 | 4 / 8 / 12 / 16 / 20 / 24 / 32（4pt 栅格） |
| 圆角 | 14（卡片）/ 9（按钮）/ 10（缩略图） |
| 字号 | 20 标题 / 12 小标题 / 11 正文 / 10 标签 / 13 主操作 |
| 强调色 | 1 个蓝（`BRAND`），其余全是中性灰阶与三个语义色 |
| 字族 | 1 个（Segoe UI，中文自动回落系统雅黑） |

## 二、颜色与对比度

全部按 WCAG 2.1 AA 实测（正文 ≥ 4.5:1，大字与控件 ≥ 3:1）。改动前的两个问题：

| 用途 | 改前 | 对比度 | 改后 | 对比度 |
|---|---|---|---|---|
| 次级文字 / 状态行 | `#8E8E93` | 3.4:1 ✗ | `#6E757F` | 4.65:1 ✓ |
| 空状态提示 | `#B0B0B8` | 2.4:1 ✗ | `#6E757F` | 4.65:1 ✓ |
| 主操作按钮 | `#007AFF` | 3.8:1 | `#1466E0` | 5.24:1 ✓ |

复算脚本（改色后请重跑）：

```python
def lin(c):
    c /= 255
    return c / 12.92 if c <= 0.03928 else ((c + 0.055) / 1.055) ** 2.4

def contrast(a, b):
    def lum(h):
        h = h.lstrip("#")
        r, g, b_ = (int(h[i:i + 2], 16) for i in (0, 2, 4))
        return 0.2126 * lin(r) + 0.7152 * lin(g) + 0.0722 * lin(b_)
    la, lb = lum(a), lum(b)
    return (max(la, lb) + 0.05) / (min(la, lb) + 0.05)
```

## 三、组件

**卡片**（`RoundedFrame`）：两层极浅投影只露出下缘 2px，加 1px 描边。不用重阴影——
在白色产品图旁边，浓阴影会把视线从图片本身拉走。

**按钮**（`Button`）：五个变体，一个页面只允许一个 `primary`。

| 变体 | 用途 | 示例 |
|---|---|---|
| `primary` | 主操作，整页唯一 | 开始转换 |
| `tonal` | 次要但想引人注意 / 选中态 | ＋ 添加图片、速度优先 |
| `secondary` | 普通按钮，带 1px 描边 | 添加文件夹、打开输出文件夹 |
| `ghost` | 弱操作，无底色 | 清空、更改 |
| `danger` | 破坏性操作 | （预留） |

每种变体都有默认 / 悬停 / 按下 / 禁用四态；禁用态统一为 `SURFACE_ALT` 底 + `INK_DISABLED` 字。

> 按钮仍然用原生 `tk.Button`，不是自绘。早期在部分显卡与老 Tk 上自绘控件会出黑块，
> 圆角换稳定性是划算的——统一感靠内边距、字号和配色建立，没有靠描边特效。

## 四、布局与响应式

- 断点 `BREAKPOINT = 900`：窗口窄于 900 时，输出位置与模型控件从"一行左右分置"折成"上下两行"，
  外边距从 20 收到 16，副标题隐藏
- 缩略图列数按可用宽度实时计算（`_cols_for`），窗口越宽排得越多，2～10 列
- 进度条宽度跟随容器；图片少到不需要滚动时，滚动条自动收起
- 完成面板在窄屏下按钮换行，避免把提示文字挤成两三个字一行
- 最小窗口 820×600

## 五、已知取舍

- 只做浅色主题。这是白底图工具，界面底色一旦染色，会影响用户对成品白底的判断
- 未做系统级 DPI 感知（保持原有的 1.25 缩放），高分屏下由 Windows 位图缩放，略软但不会错版
- 圆角按钮做不到（Tk 限制），见上文
